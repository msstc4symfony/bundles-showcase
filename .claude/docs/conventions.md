# Соглашения bundles-showcase

- **Три независимых приложения.** gateway, orders, billing не делят код: у каждого свой `composer.json`, Kernel и
  тесты. Общие инфраструктурные мелочи (`RedisConnectionGuard`, тестовый `FakeRedis`, классы сообщений
  `App\Message\*`) **сознательно скопированы** — так приложения остаются независимыми, как отдельные сервисы.
  При правке такого класса меняй все копии в том же коммите (`grep -rl <Class> apps/`).
- Публичный сервис только для тестов — в `when@test` секции `services.yaml` (`OrdersStub`, `IdempotencyStore`).
  `IdempotencyStore` публичен целиком (а не `LockFactory`): тест подменяет store с недоступным lock-хранилищем,
  не трогая общий `lock.factory`, которым пользуются другие сервисы.
- Тестовые даблы интерфейсов — с телом методов и `#[Override]` (Rector удаляет «пустые» методы).
- В e2e значения из фич (ключи идемпотентности, request id) — через `RunScoped::id()`; метрики сравниваются
  через «remember → grows by», а не абсолютными значениями.
